### 2. Raw Material Stability Dashboard

**Power BI | Power Query | DAX | Excel**

Procurement analytics dashboard designed to monitor raw-material readiness, allocation status, pending orders, and customer-level performance in a manufacturing environment.

**Highlights**

- Developed management-level procurement KPIs
- Monitored proceedable, allocated, and pending orders

### 3. Customer Support SLA & Ticket Performance Dashboard

**Power BI | Power Query | DAX | Excel**

End-to-end customer-support analytics project covering data profiling, validation, transformation, SLA analysis, ticket backlog, customer satisfaction, and product-level support performance.

**Highlights**

- Analyzed **8,469 customer-support tickets**
- Built KPIs for ticket volume, resolution rate, SLA compliance, and customer satisfaction
- Identified **1,365 invalid closed-ticket timestamp sequences**
- Excluded unreliable records from time-based SLA calculations
- Analyzed SLA performance by priority and support channel
- Evaluated backlog, ticket types, product support volume, and satisfaction
- Included the Excel validation workbook and Power BI report for project transparency
